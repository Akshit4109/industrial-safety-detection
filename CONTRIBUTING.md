# Contributing

Thanks for taking the time to contribute.

1. Create a focused branch from `main`.
2. Keep changes small, documented, and covered by tests where practical.
3. Run `pytest -v` and `python scripts/verify_env.py` before opening a pull request.
4. Describe the problem, implementation, validation steps, and any limitations in the pull request.

Please do not commit raw datasets, model weights, experiment logs, API keys, or other large/generated artifacts. Use DVC storage or a release asset for shareable model files.
